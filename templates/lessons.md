# Lessons

Corrections that apply to every session in this brain. The install copies this file to `lessons.md` in the LLM brain, and a session-start hook can print it.

Each lesson has a short bold name, a date, the rule, and a `Why:` line. Give every new lesson a name, so that a session can cite it by that name. Add new lessons at the top.

A correction that belongs to one project goes on that project's card in `wiki/workblocks/`, under `## Lessons`, not here. A lesson that agents keep breaking should become a check (a hook, a lint or a test) instead of a longer rule.

Format:

```
- YYYY-MM-DD · **Short name.** The rule, as one or two instructions in the imperative.
  Why: what went wrong, or what the author said, in one or two sentences.
```
