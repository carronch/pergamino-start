# Purpose: writing-for-agents

## Why it exists

It is the reference for writing documents that agents read: skills, `AGENTS.md`, `CLAUDE.md`, and docs reached by a pointer. It names the levers: context load, context pointers, progressive disclosure, sprawl, leading words, negation, single source of truth, relevance and sediment. `retro` calls it first. Skills and rule files grow long over time (a single ingest skill can pass 400 lines; a synced `AGENTS.md` can pass 50,000 bytes), and this is the guide for cutting them.
